# WOOWANGTHON TEAM 23

## 프로젝트 소개

**스크롤 메이트**: 사용자가 배우고 싶은 것(토익, 운전면허, 자격증, 수업 복습 등)의 자료를 올리면, 쇼츠를 넘기는 일상 속에서 그 자료로 만든 문제를 카드로 보여 주는 안드로이드 앱.

- 자료(PDF, PPTX)에서 AI가 OX·단답 문제와 근거 문장을 미리 만들어 기기에 저장함
- 쇼츠를 넘길 때 문제 카드가 뜨고, 사용자가 인터럽트 허용 범위와 올릴 자료를 정함
- 문제를 언제, 무엇을 낼지는 규칙이 정하고, AI는 문제 생성 같은 언어 작업을 맡음
- 해커톤 주제 "AI는 동료가 될 수 있는가"에 대한 답으로, 따로 시간을 내서 공부하라고 하지 않고 일상의 스크롤 자리에 먼저 찾아오는 동료를 만듦

구현된 범위와 AI 활용 범위는 [ai-scope.md](ai-scope.md)에 정리함. API 계약은 [api.md](api.md)를 따름.

## 구조

```
[ 안드로이드 앱 (FE) ]                 [ Fly.io 컨테이너 1대 ]                     [ 외부 ]
 홈, 자료 올리기, 학습 주제              BE (FastAPI, SQLite)  ──>  AI (FastAPI)  ──────>  OpenAI API
 접근성 서비스: 쇼츠 위 문제 카드         자료 받기, 글자 뽑기,        문제 생성·검사            gpt-5.4-mini
 기기 DB(Room): 문제, 풀이, 학습 주제     조각 나누기, 작업 큐         (컨테이너 안에서만 접근)
        │                                      ▲
        └──── HTTPS https://scrollmate-be.fly.dev ────┘
```

- 앱은 BE만 부르고, AI 서비스는 같은 컨테이너 안에서만 접근할 수 있음
- 문제는 서버가 미리 만들어 기기에 저장하므로 카드는 오프라인에서도 뜸
- 학습 주제, 시험일, 재출제 계산은 기기에만 있음. 더 자세한 구조는 [architecture.md](architecture.md)에 있음

## 기술 선택

| 선택 | 이유 | 한계 |
|---|---|---|
| 접근성 서비스와 오버레이로 쇼츠 위에 카드를 띄움 | 다른 앱 위에 카드를 띄우고 쇼츠 진입·넘김을 알 수 있는 안드로이드의 정식 방법임 | 사용자가 설정에서 켜야 하고, 유튜브 앱 화면 ID에 의존함. 안드로이드만 지원 |
| 문제를 서버에서 미리 만들어 기기에 저장 | 카드를 띄울 때 AI 응답을 기다리지 않고 오프라인에서도 뜸 | 새 문제는 다음 동기화(15분 주기, 앱을 열 때)에 들어옴 |
| 규칙은 기기에서 계산하고 AI는 언어 작업만 맡김 | 카드 등장, 출제 주제, 채점, 재출제는 규칙으로 정하는 편이 예측되고 시험할 수 있음 | 규칙의 값(확률, 간격, 가중치)은 임의로 정했고 효과를 검증하지 않음 |
| 단답 채점에 LLM을 쓰지 않음(2026-11-08) | 출제 단계에서 정답을 명사 하나로 만들고 허용 답안과 글자로 비교함 | 같은 뜻의 다른 표현을 놓칠 수 있음 |
| OpenAI API(gpt-5.4-mini)로 문제 생성(2026-11-11) | 처음에는 로컬 모델 5종을 비교해 qwen3.5:9b를 골랐으나, 서버(Mac)를 심사 종료까지 켜 둘 수 없어 폐기하고 OpenAI로 바꿈 | 자동 검사로만 평가함(결함 없음 85%). 정답이 맞는지 사람이 채점하지 않음. 글자가 OpenAI로 전송됨 |
| Fly.io에 BE와 AI를 한 컨테이너로 배포 | 고정 주소와 상시 운영을 위해 Mac 서버를 대체함 | 로그인이 없어 기기 ID와 기기별 한도로만 막음 |
| 구글 로그인, 오답노트, 인스타그램 릴스는 넣지 않음 | 범위를 줄여 핵심(자료, 카드, 재출제)을 완성함 | 한계로 문서에 적음 |

## 자료 사용 안내

- 올리는 자료는 본인이 학습 용도로 쓸 수 있는 것이어야 함
- 올리는 자료의 저작권과 이용 권한은 올리는 사람에게 있으며, 권한이 없는 자료를 올려 생기는 문제의 책임은 올린 사람에게 있음. 앱의 자료 올리기 화면에도 같은 안내(저작권·이용 권한, OpenAI 전송)를 보여 줌
- 서버는 올린 파일에서 글자만 뽑아 문제를 만듦. 원본 파일은 서버의 DB나 폴더에 보관하지 않음. 다만 1MB가 넘는 파일은 요청을 처리하는 동안 임시 파일로 잠시 쓰이고 처리가 끝나면 지워짐
- 뽑은 글자(자료 본문)와 만든 문제는 자료를 삭제할 때까지 서버에 보관됨. 자동으로 지워지는 기간은 없음
- 자료를 삭제하면 서버에서 그 자료의 글자, 문제, 풀이 결과, 신고 기록이 함께 지워짐. 기기별 업로드 횟수 기록(자료 내용과 무관한 숫자)은 남음
- 글자는 문제를 만들기 위해 서버에서 외부 AI 서비스인 OpenAI API(gpt-5.4-mini)로 전송됨. 전송된 글자를 OpenAI가 보관하거나 이용하는 조건은 OpenAI 약관을 따르며, 이 문서에서는 확인하지 못함
- 쇼츠 시청 기록(본 시간, 넘긴 횟수, 카드 결과 수)은 기기에 저장하고, 오늘의 한마디를 위해 하루 합계만 서버로 보냄. 영상 제목, 채널, 댓글, 계정은 수집하지 않음
- 강의 파일과 교재는 이 저장소에 올리지 않음. 시연·테스트용 샘플 자료는 위키백과 문서를 옮긴 [test-materials](test-materials/)에 있음(CC BY-SA 4.0)
